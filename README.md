# Weather CLI — Консольный прогноз погоды

[![Java](https://img.shields.io/badge/Java-17%2B-orange.svg)](https://www.oracle.com/java/)
[![Maven](https://img.shields.io/badge/Maven-3.8%2B-blue.svg)](https://maven.apache.org/)
[![API](https://img.shields.io/badge/API-OpenWeatherMap-yellow.svg)](https://openweathermap.org/)

Консольное Java-приложение для получения актуального прогноза погоды в любом городе мира с помощью [OpenWeatherMap API](https://openweathermap.org/api).

---

## Возможности

- **Мультиязычность**: поддержка названий городов на русском и английском языках (`Москва`, `Санкт-Петербург`, `London`, `New York` и др.).
- **Поддержка сложных названий**: корректное URL-кодирование для городов с пробелами, дефисами и спецсимволами.
- **Подробная сводка с наглядными иконками**:
  - `📍` Город и страна;
  - `☁️` Погодные условия (ясно, пасмурно, дождь и др.);
  - `🌡️` Температура и ощущение («feels like») в градусах Цельсия (°C);
  - `💧` Влажность воздуха (%);
  - `🧭` Атмосферное давление (в мм рт. ст. и гПа);
  - `💨` Скорость ветра (м/с).
- **Интерактивный режим**: последовательный запрос погоды для нескольких городов без перезапуска программы.
- **Надёжная обработка ошибок**: информативные сообщения при опечатках в названии города (HTTP 404), сбоях сети или ошибках авторизации (HTTP 401).
- **Безопасная работа с API-ключом**: поддержка локального файла `.env`, переменных окружения `OPENWEATHER_API_KEY` или интерактивного ввода. Никаких захардкоженных секретов в репозитории.
- **Автономный JAR**: сборка исполняемого fat-JAR со всеми зависимостями через `maven-shade-plugin`.

---

## Требования

- **Java Development Kit (JDK)**: версия **17** или выше.
- **Apache Maven**: версия **3.8** или выше (для сборки из исходного кода).
- Бесплатный API-ключ OpenWeatherMap и доступ в Интернет.

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/koko4267/weather.git
cd weather
```

### 2. Сборка проекта

Сборка автономного исполняемого JAR-файла со всеми зависимостями:

```bash
mvn clean package
```

После завершения сборки готовый файл будет находиться по пути `target/weather.jar`.

### 3. Запуск

```bash
java -jar target/weather.jar
```

## Настройка API-ключа

Для работы приложения требуется бесплатный ключ OpenWeatherMap:
1. Зарегистрируйтесь на сайте [OpenWeatherMap](https://home.openweathermap.org/users/sign_up).
2. Перейдите в раздел [API Keys](https://home.openweathermap.org/api_keys) и скопируйте ваш ключ.

Вы можете передать ключ **любым удобным способом**:

### Способ 1: Файл `.env` (Рекомендуется для локальной разработки)
Скопируйте шаблон `.env.example` в `.env` (этот файл уже в `.gitignore` и не попадёт в репозиторий):
```bash
cp .env.example .env
```
И укажите в нём ваш ключ:
```env
OPENWEATHER_API_KEY=ваш_секретный_ключ
```

### Способ 2: Переменная окружения

#### Windows (PowerShell):
```powershell
$env:OPENWEATHER_API_KEY="ваш_секретный_ключ"
java -jar target/weather.jar
```

#### Windows (CMD):
```cmd
set OPENWEATHER_API_KEY=ваш_секретный_ключ
java -jar target/weather.jar
```

#### Linux / macOS:
```bash
export OPENWEATHER_API_KEY="ваш_секретный_ключ"
java -jar target/weather.jar
```

### Способ 3: Интерактивный ввод
Если ключ не найден ни в `.env`, ни в переменных окружения, программа сама предложит ввести его в консоли при старте.

## Структура проекта

```
weather/
├── src/
│   ├── main/
│   │   ├── java/org/example/
│   │   │   ├── Main.java              # Точка входа в приложение, консольный интерфейс
│   │   │   ├── WeatherService.java    # HTTP-клиент, URL-кодирование и парсинг OpenWeatherMap API
│   │   │   ├── WeatherData.java       # Модель данных погоды (record)
│   │   │   └── WeatherException.java  # Пользовательское исключение для ошибок API
│   │   └── resources/
│   │       └── META-INF/
│   │           └── MANIFEST.MF        # Манифест JAR
│   └── test/
│       └── java/org/example/
│           └── WeatherServiceTest.java # Модульные тесты (URL encoding, парсинг JSON)
├── .env.example                       # Шаблон для конфигурации API-ключа
├── .gitignore                         # Правила игнорирования файлов сборки, секретов и IDE
├── pom.xml                            # Конфигурация Maven и плагин сборки shade
└── README.md                          # Документация проекта
```
